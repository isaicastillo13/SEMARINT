# SEMARINT Landing Page

Landing page corporativa de **SEMARINT (Servicios Aéreos Marítimos Internacionales, S.A.)** desarrollada con React, Vite y Tailwind CSS.

## Estructura base

- Secciones desacopladas en `src/components/sections/`.
- Layout en `src/components/layout/`.
- Contenido provisional centralizado en `src/data/siteContent.js`.

## Desarrollo

```bash
npm install
npm run dev
```

La aplicación se ejecuta en la URL local que indique Vite (por defecto `http://localhost:5173`).

## Scripts disponibles

- `npm run dev`: inicia entorno local con recarga en caliente.
- `npm run build`: genera build de producción.
- `npm run preview`: sirve el build generado localmente.
- `npm run lint`: ejecuta ESLint sobre el proyecto.
